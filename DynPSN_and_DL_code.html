CNN + LSTM Deep Learning Pipeline

This pipeline supports:

  • Generating 72 structured datasets from dGDV files
  • Creating dataset-specific deep learning model scripts
  • Training CNN–BiLSTM architectures across all datasets
  • Processing aggregate evaluation results

Workflow Overview

  1. Dataset generation
  2. Model generation and training
  3. Results processing

Dataset Generation

bash make_dataset_all.sh
bash make_dataset.sh dataset-01.txt

Model Generation

python make_models.py relu_model_template_cv.py

Model Architectures

  • Relu – 3 CNN + 1 BiLSTM (ReLU)
  • Leaky – 3 CNN + 1 BiLSTM (LeakyReLU)
  • Paper – 2 CNN + 3 BiLSTM (original architecture)
  • Deep – 3 CNN + 3 BiLSTM (deep CNN + deep LSTM)

Results Processing

python process_results.py
python extract_cm.py

Outputs include aggregate misclassification rates and confusion matrices.

Dynamic Graph Convolutional Network (DGCN)

A PyTorch framework for temporal graph classification.

Architecture

  • Multi-layer GCN with residual connections
  • Attention-based graph-level pooling
  • Multi-head temporal self-attention
  • MLP classification head

Run

python DGCN.py

Cross-Validation Workflow

  1. Load dataset and map labels
  2. Partition into 5 folds
  3. Train and validate
  4. Save best model per fold

Static Graph Convolutional Network (GCN)

A PyTorch framework for static graph classification.

Architecture

  • Stacked GCN layers with residual connections
  • Attention-based graph pooling
  • MLP classifier
  • 5-fold cross-validation

Run

python GCN.py

Workflow

  1. Load graphs and labels
  2. Partition into 5 folds
  3. Train and evaluate
  4. Save best model per fold
